1 יוצרים תיקיית נחיתה

כל קמפיין מקבל HTML ונכסים משלו תחת subdomains, בלי לשבור את עמוד החנות הקיים.

2 מחברים Host

השרת בודק את הדומיין המבוקש ומגיש את העמוד המתאים כאשר הבקשה מגיעה מהסאב-דומיין.

3 מוסיפים DNS ב-Railway

מגדירים את הדומיין ב-Railway, מעתיקים את רשומת ה-DNS לספק הדומיין, וממתינים לאישור SSL.

מוכן לקמפיין הבא.

החלף את הטקסטים והמוצר בעמוד הזה, קבע את LANDING_SUBDOMAIN_HOST לכתובת הרצויה, והוסף את הדומיין ב-Railway. אין צורך לפתוח GitHub repo חדש בשביל זה.
